# MTEC Project 7 | Komorebi Architecture Website

A four-page architecture website developed for Project 7 in the Web Programming and Development course at MTEC.

The project explores how AI can be used as a development partner while building a responsive website with Tailwind CSS. The goal was to create a cohesive experience across the home, projects, about, and contact pages while maintaining a consistent visual identity.

## Project Goals

- **AI as a Development Partner:** Use AI throughout the planning, development, refinement, and problem-solving process.
- **Tailwind CSS:** Build the interface with utility-first styling and reusable design patterns.
- **Responsive Design:** Create layouts that work clearly and comfortably across mobile, tablet, and desktop screen sizes.
- **Consistent Branding:** Maintain a unified theme through shared typography, color, spacing, imagery, and component styling.
- **Working Navigation:** Connect all four pages with clear, functional navigation and accessible interactive states.
- **GitHub Version Control:** Store the project on GitHub with organized commits that document the development process.
